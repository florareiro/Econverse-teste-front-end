## 1- no terminal de comando clone o repositório

git clone https://github.com/florareiro/Econverse-teste-front-end.git

## 2- entre na pasta do projeto

cd Econverse-teste-front-end

## 3- instalar dependências

npm install

## 4- rodar aplicação localmente

npm run dev

## 5- acessar a aplicação

http://localhost:5173/
